Sincronização na nuvem
Liga uma conta gratuita Firebase para o calendário sincronizar em tempo real entre o teu telemóvel e o dela.
1. Vai a console.firebase.google.com ↗ e cria um projeto grátis
2. No menu, entra em Firestore Database → Criar base de dados (modo de teste)
3. Vai a Definições do projeto ⚙️ → geral, cria uma "App Web" e copia o bloco firebaseConfig
4. Cola esse bloco todo aqui em baixo
